# AXIOM.tech — концепт сайта

Статический сайт (HTML + CSS + JS без сборки и фреймворков). Всё на сайте сгенерировано нейросетью — это концепт вымышленной компании.

## Как посмотреть

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Структура

```
index.html          вся разметка, секции идут сверху вниз
style.css           стили и адаптив (токены размеров и отступов в начале файла)
main.js             логика: первый экран, Lenis-скролл, кейсы, этапы, калькулятор, вопросы, форма
viewer3d.js         3D-просмотр деталей и заготовки калькулятора (three.js)
lib/                three.js, Lenis (локально, без CDN)
css/                brackets.css (угловые скобки), progress.css, cursor.css
assets/img/         логотипы и картинки; assets/models/ — 3D-модели (GLB)
assets/fonts/       IBM Plex Mono и IBM Plex Sans (woff2, лицензия SIL OFL 1.1 в LICENSE.txt)
v3/                 заглушка: старый адрес /v3/ перенаправляет на главную
```

Страница `v3/index.html` оставлена только для старых ссылок.

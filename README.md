# AXIOM.tech — сайт

Статический сайт (HTML + CSS + JS без сборки), вёрстка по экспорту из Тильды.

## Как посмотреть

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом тоже можно, но лучше через сервер.

## Структура

```
index.html          вся разметка, секции идут сверху вниз как на сайте
css/style.css       основные стили, сетка, адаптив (≤1100px и ≤900px, ≤520px)
css/effects.css     анимации: «печать» логотипа, машинка в заголовках, сканирование слайдов, неон
css/brackets.css    угловые скобки у карточек (цвет: .bk--orange / --cream / --ink)
css/calc.css        калькулятор
css/form.css        форма заявки
css/progress.css    полоса «печати» внизу экрана
css/cursor.css      курсор-визир
js/main.js          все скрипты; настройки — в самом начале файла
assets/             картинки, видео, логотип
```

## Что нужно настроить

- **Кадры первого экрана** грузятся из репозитория `applehead13/Axiom-3D` (`FRAMES_URL` и `FRAMES_COUNT` в начале `js/main.js`). В репозитории 98 кадров.
- **Отправка заявок**: пока адрес не задан (`LEAD_ENDPOINT` в `js/main.js`), форма только показывает «Заявка отправлена» и ничего не отправляет.
- **Контакты в подвале** (телефон, почта, ИНН) — заглушки из исходного макета.
- **Плавный скролл** подключается библиотекой Lenis с unpkg. Если она не загрузилась, сайт работает с обычной прокруткой.

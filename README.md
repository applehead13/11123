# AXIOM.tech — сайт

Статический сайт (HTML + CSS + JS без сборки), вёрстка по экспорту из Тильды.

## Как посмотреть

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом тоже можно, но лучше через сервер.

## Структура

```
index.html          вся разметка, секции идут сверху вниз как на сайте
css/style.css       основные стили, сетка, адаптив (≤1100px и ≤900px, ≤520px)
css/effects.css     анимации: «печать» логотипа, машинка в заголовках, сканирование слайдов, неон
css/brackets.css    угловые скобки у карточек (цвет: .bk--orange / --cream / --ink)
css/calc.css        калькулятор
css/form.css        форма заявки
css/progress.css    полоса «печати» внизу экрана
css/cursor.css      курсор-визир
js/main.js          все скрипты; настройки — в самом начале файла
assets/             картинки, видео, логотип
```

## Правила вёрстки

- Контейнер до 2400px по центру, поля `--gutter` 20→80px, отступы между секциями `--section-gap` 60→160px, внутри карточек `--card-pad` 20→40px.
- Размеры текста только через токены `--fs-h1 / h2 / sub / text / small` (clamp: 375 → 1440 → потолок) и `--fs-label` для мелких служебных подписей. Все они в начале `css/style.css`.
- Карточки портфолио не растягиваются: 1 колонка до 879px, 2 — от 880, 3 — от 1440, 4 — от 1920, 5 — от 2560.
- Первый экран не привязан к 100vh: минимальная высота в rem.
- **Сетка-подсказка**: клавиша `G`, кнопка вверху по центру или `?grid` в адресе.

## Стекло и HDRI

Стеклянные блоки (вопросы, форма, калькулятор, список материалов, полоса «печати») описаны в `css/glass.css`.
Отражение в стекле берётся из `assets/img/glass-env.jpg`: это карта окружения из HDRI
[Studio Small 09](https://polyhaven.com/a/studio_small_09) (Poly Haven, лицензия CC0). Исходник лежит в `hdri/`.

Как собрать карту заново или заменить HDRI:

```bash
pip install opencv-python-headless numpy OpenEXR
python3 tools/make_glass_env.py hdri/studio_small_09_2k.exr --exposure 0.9 --band 38 --blur 9
```

Принимаются `.hdr` и `.exr`. Свет слишком яркий или тусклый — меняйте `--exposure`; повернуть окружение — `--yaw 90`.
Скрипт перезаписывает `glass-env.jpg`, больше ничего менять не нужно.

## Что нужно настроить

- **Отправка заявок**: пока адрес не задан (`LEAD_ENDPOINT` в `js/main.js`), форма только показывает «Заявка отправлена» и ничего не отправляет.
- **Контакты в подвале** (телефон, почта, ИНН) — заглушки из исходного макета.
- **Плавный скролл** подключается библиотекой Lenis с unpkg. Если она не загрузилась, сайт работает с обычной прокруткой.
